# Dorados de Chihuahua — LMB 2026

Advance site for the Dorados de Chihuahua and the rest of the 2026 Mexican League.

Player lines are the 2026 summer season from the MLB Stats API Mexican League feed. Pitch mix, plate location, and bats/throws are not in that feed, so those charts stay empty.

Live site: https://colbymorris08.github.io/DoradosLMB/
